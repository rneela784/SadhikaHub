QUESTION 21 / 23hard

Physics: A 2-ohm resistor and a 4-ohm resistor are connected in series to an ideal 12-volt battery. What current flows? In series, resistances add, and current = voltage divided by total resistance.

Need a hint?

Find the combined resistance first, then use the current rule given in the question.

QUESTION 22 / 23medium

Chemistry: A model contains 3 carbon dioxide molecules (CO2) and 2 water molecules (H2O). How many oxygen atoms are there altogether?

Need a hint?

Each CO2 molecule contains two oxygen atoms; each H2O molecule contains one. Count the two groups separately.

QUESTION 23 / 23hard

Mathematics: A small theatre has 5 rows. The first row has 6 seats, and each following row has 3 more seats than the row before it. How many seats are there altogether?

Need a hint?

Write the seat counts for all five rows, then add them. The increases are equal.
